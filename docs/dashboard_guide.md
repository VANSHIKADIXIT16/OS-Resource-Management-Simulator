# Interactive Dashboard Guide

## What it adds

`dashboard.py` provides a local browser interface for the existing simulator.
It imports the existing algorithm functions in `modules/`, uses the existing
JSON samples in `data/`, and displays reports generated by
`analysis/performance.py`. The terminal app (`main.py`) is retained.

## Files and exact locations

Copy the files from this add-on into the existing project:

- `dashboard.py` → project root, beside `main.py`
- `dashboard.sh` → project root, beside `run.sh`
- `requirements.txt` → replace the existing root file with the supplied updated file
- `README.md` → replace the existing root file with the supplied updated file
- `.gitignore` → replace the existing root file with the supplied updated file
- `docs/dashboard_guide.md` → inside the existing `docs/` directory

No files in `modules/`, `analysis/`, or `data/` need to be moved or replaced.
The dashboard depends on their existing functions and data formats.

## Install and launch on macOS

```bash
cd ~/Desktop/OS-Resource-Management-Simulator
source venv/bin/activate
python -m pip install -r requirements.txt
chmod +x dashboard.sh
./dashboard.sh
```

Open the local URL Streamlit prints, normally `http://localhost:8501`.
Stop the dashboard with `Control+C` in the terminal.

The original terminal interface remains available:

```bash
./run.sh
```

## Pages

- Overview
- CPU Scheduling: editable processes, algorithm comparison, metrics, Gantt charts
- Memory Management: editable partition/process inputs and fragmentation comparison
- Deadlock Safety: editable Allocation/Max/Available values and safe sequence
- Disk Scheduling: editable queue, head, disk size, SCAN direction and movement
- Performance Reports: view/download CSVs and display charts
- Sample Data: inspect/download samples and explicitly upload replacements

Uploaded replacement samples are saved into the existing `data/` folder.
Back up originals before replacing them. Inputs edited on algorithm pages are
used for that simulation run and are not automatically written to JSON.

## Architecture and limitations

The dashboard is local to your Mac; it is not a hosted/public website. It uses
the same Python algorithm modules as the CLI, so fixes to those algorithms
apply to both interfaces. The memory simulator remains fixed-partition
allocation. SCAN includes travel to the selected disk boundary.
